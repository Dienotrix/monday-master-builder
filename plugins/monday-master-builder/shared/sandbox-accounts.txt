# shared/sandbox-accounts.txt
# Two lists in one file, read by three places: the binding step of a new client record
# refuses a slug or account id listed here unless the record is account_kind: sandbox, and
# refuses a sandbox record binding to anything else (ARCHITECTURE 8.2 step 4); the drift
# door runs write probes only against a bound account listed here on a record marked
# account_kind: sandbox (3.10); and demo_check.py gate fails any run-sheet step that opens
# an account marked never-demo (5.4, 9.11). Sandbox scenarios (BUILD-PLAN 4.6) bind a
# client/2 record with account_kind: sandbox whose id matches the sandbox row.
#
# Syntax. One entry per line; a line starting with # is a comment; blank lines are ignored.
# Fields are separated by " | " in this order:
#   kind | account_id | account_slug | workspace_id | label | note
# kind is sandbox or never-demo. workspace_id is the one workspace the entry is scoped
# to, or * for the whole account. The account host is <account_slug>.monday.com, which is
# the form a run-sheet step or a link carries, so gate matches on the slug as well as the id.
#
# Both lists ship empty. Entries name the user's own accounts and workspaces, which never
# belong in the shipped plugin (A12); where the user's local entries live is settled in
# stage 1b. With no sandbox row there is nowhere for write probes and sandbox scenarios to
# run, so they are refused, which is the safe default.

# [A11-1] Where write probes and sandbox scenarios run. Open decision, no default assumed:
# the question is asked before any sandbox run outside the current test workspace and
# before 1.0.0.

# never-demo: the user's own live operational account, the one the connector is signed
# into, which carries staff, engagement records and client commercials (9.11). Never opened
# on a shared screen, never bound to a client record. A sandbox row and a never-demo row may
# name the same account: the sandbox row answers where tests may write, the never-demo row
# answers what may not be shown, and they do not cancel each other. A separate demo
# environment, if one is set up, is a new sandbox row and part of the [A11-1] answer.
