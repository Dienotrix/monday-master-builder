# shared/leak-terms.txt
# The global denylist read by scripts/leak_lint.py (ARCHITECTURE 9.6). It holds the
# terms that must never reach client-facing material: the plugin and assistant names,
# method vocabulary, pain and record ids, evidence markers and id patterns. The user's own
# firm name and its renderings are per user and come from local/leak-terms.txt under
# MMB_HOME, in this same syntax (see class: firm below). Client-derived figures, quotes,
# objection text, stakeholder assessments and other clients' names are per-record and are
# built by the lint from the record, not listed here. Reserved monday column ids are not
# leak terms; they live in native-objects.md.
#
# Where this file applies: planned names at the blueprint stage; every monday text payload
# before its write; everything in drafts/, sop/ and deliverables/; the text and document
# properties of rendered Word and PDF files; the doc-copy text read back; live object names
# during the audit; and SUMMARY.md under the copied-run and quote-length rules. Internal
# files (the record, shared/, skills) legitimately contain these terms.
#
# Syntax. One term per line. A line starting with # is a comment; blank lines are ignored.
#   term               a literal, matched case-insensitively wherever the characters on
#                      either side are not letters or digits
#   class: <name>      every line below, until the next class:, belongs to this class,
#                      and the lint reports the class beside each hit
#   re: <pattern>      a Python regular expression, matched case-insensitively
#   phonetic: <term>   the term is also matched by the phonetic-variant rule of 9.6,
#                      which catches renderings this list does not spell out
#   whitelist: <term>  a legitimate use the phonetic rule directly above it never blocks;
#                      the test suite asserts no false positive on it
# The per-client allowlist may clear a row of class method only. Rows of every other class
# are never cleared by an allowlist (9.6). A term that is also the client's own vocabulary
# survives with a caution rather than being removed.
