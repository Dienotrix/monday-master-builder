No probe writes to a monday account; if one is ever extended into a write it runs in the one test workspace the live-test rules allow, and the row says so [A11-1].

## What the capability check settled, and what it did not

`cowork-capabilities.md` (2026-09-11) is read-only fact about the two Cowork shells: cloud Python 3.11 with the document toolchain and no installs; device Python 3.10 scoped to connected folders under `$HOME/mnt/`, about 45 seconds per call, deletes prompting once; no `gh` in either; `storage.googleapis.com` and `mcp.monday.com` refused from the cloud shell; subagents, web fetch and the monday connector present. That answers the cloud halves of S0-2 and S0-10, two steps of S0-3 and the Cowork half of S0-13. It says nothing about `${CLAUDE_PLUGIN_ROOT}`, plugin agents, wildcards, the door flag, Project instructions, fetch from skill text, hooks, or the `MMB_HOME` root, which is why those rows are `not-run`.
